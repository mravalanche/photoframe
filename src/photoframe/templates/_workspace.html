RESET & RECOVERY

Reset Photoframe to defaults?

This permanently deletes the saved photo-provider credential, server and album configuration, frame and timing settings, display overrides, current selection, and downloaded photo cache. Network settings return to HTTP on 127.0.0.1:8000, so Photoframe may restart at that address. Photoframe, its system service, and your colour theme will remain installed. You’ll need your server URL and API key to reconnect.
